NixOS Build Monitor

About

Real-time monitoring dashboard for NixOS build activity. Displays live system metrics and build output from the nix-daemon.

Features

  • Live Metrics: CPU, RAM, Disk, and Network usage with real-time graphs
  • Build Output: Streaming terminal display of nix-daemon activity
  • Collapsible Widgets: Click any metric widget to expand all details
  • Dark/Light Mode: Automatically adapts to system preference
